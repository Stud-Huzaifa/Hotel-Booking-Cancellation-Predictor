### Hotel Booking Cancellation Predictor 🏨🧠

A Deep Learning project that predicts whether a hotel booking is likely to be **cancelled or not** using an Artificial Neural Network (ANN) built with **TensorFlow/Keras**.

The project covers **EDA, data cleaning, feature engineering, categorical encoding, feature scaling, ANN training, overfitting analysis, L2 regularization, EarlyStopping, model experimentation, and evaluation**.

**Final Model Performance:**
**Accuracy:** 86.7% | **F1-Score:** 81.5% | **ROC-AUC:** 94.2%

**Tech:** Python • Pandas • Scikit-learn • TensorFlow • Keras • Matplotlib
